# Замена прежней установки на AI poise

Это замена пакета, а не совместимое обновление. Старое пространство имён и
исполняемая команда после операции отсутствуют.

Соберите wheel `ai-poise`, затем выполните единственный поддерживаемый сценарий:

```bash
python tools/upgrade_to_ai_poise.py \
  --python /путь/к/целевому/python \
  --wheel /путь/к/ai_poise-0.16.1-py3-none-any.whl
```

Сценарий последовательно выполняет
`pip uninstall -y agent-harness-happy-path` и устанавливает переданный wheel
`ai-poise` без обращения к индексу пакетов. После замены проверьте:

```bash
/путь/к/целевому/poise --help
```

Команда `harness` и импорт `harness` после замены намеренно не поддерживаются.
