# Восстановитель накопительной копии

Используйте [общую инструкцию](../README.md). Этот подкаталог содержит проверки
целостности и реконструкцию конкретного формата базы PS-DEV-002. `--parts-directory`
либо `--base` задают исходную базу; `--checkpoint`, `--checkpoint-sha256` и
`--destination` задают накопительную копию и новый корень. `--install-operator`
устанавливает исходные стабильные wheels офлайн после размещения файлов.

Состояние Task и blockers берутся из текущего CHECKPOINT/public owner, не из этого
README. Прежний блокер commit-pattern уже исправлялся отдельно; восстановитель
не применяет ни старый запрет, ни новую настройку самовольно. Он сохраняет именно
снимок manifest. Роль и Session не воссоздаются от имени прежнего caller.
