## Явно заменённые формулировки

- MCP-first заменено пользовательским предпочтением CLI; обязательные IDE-возможности остаются специальным случаем.
- Собственный orchestration/scheduler моделей снят: выбор runtimes и назначения остаются пользователю.
- Регистрация changed files агентом заменена наблюдением Git.
- File-backed секции заменены текстами в SQLite.
- Общие process fragments между goal types отвергнуты вариантом A; переиспользование library code позднее прямо потребовано.
- Автоматическое full testing в конце development/task/sprint отвергнуто.
- Отдельный terminal failed задачи отвергнут; ошибки конкретных команд не отменены.
- Смысловые описания существующих артефактов отвергнуты в пользу пути и внутреннего ID.
- Все ошибки в докладе заменены обязательным показом Incidents самого Harness; рабочие результаты тестов отражаются по смыслу задачи.
- Самостоятельное исполнение многих этапов подряд заменено последним явным поручением «один этап → доклад → решение пользователя».
- Ручной stage-result JSON — прежний интерфейс; новая целевая декларативная подача реализуется DDD-04B.

## Связь с текущей разработкой

Список не является поводом замораживать согласованный DDD-04A. В нём выполняется уже порученный batch-редактор конфигурации. Неясные общие правила не включаются в AGENTS.md автоматически. После вашей классификации нужно обновить конкретные rules/requirements, а не создавать ещё один параллельный источник истины.
