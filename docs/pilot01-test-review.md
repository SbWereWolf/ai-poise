# Осмотр тестов HARNESS-PILOT-01

Обновлено: **2026-09-07T14:15:55+05:00**.

Осмотр выполнен тем же агентом, не независимым reviewer. Тесты проверяют реальные файлы,
общий load_config, Git readiness и обычный WorkTools bootstrap. Positive fixtures передают
полные настройки; отсутствие обязательного ответа не компенсируется default. Проверяются
back/change/keep(false), abort, EOF, ограничения анкеты, конфликтующий повтор, изменённый
после публикации конфиг, неполный/устаревший source process и symlink.

Отказ до публикации моделируется в границе rename (не заменяет испытания power-loss).
Отдельный тест запускает self-pilot на закоммиченной копии настоящих src/tests/config;
команда проверяет только tests/projects, поэтому тест не вызывает сам себя рекурсивно.
Реальная принимающая Task остаётся verified. Синтетических user_accept нет.

Первые новые tests закончились collection RED из-за отсутствовавшего API. Четыре поздних
регрессии осмотра действительно воспроизвели поведение первой реализации (неверный порядок
валидации, Python TypeError для Git-полей, пересечение state/manifest). Затем исправлены.
