# Independent T029 contract fixtures

These UTF-8 literals are authored from the accepted T029 execution-only contract,
not generated by a production parser, enum, serializer or output update command.
The fake owner is a standalone external process with the non-reserved application
ID `widget-external`. It invokes the supplied public subject argv, records actual
cwd/environment/context, and has explicit failing/resource/drift modes.

The test harness replaces only marked host paths and observed platform/version
values in configuration. Expected fields, order, statuses, error codes and raw
owner outputs are literals. Dynamic SHA-256 assertions use the independent
standard-library digest of arranged bytes, never production helper code.
No test automatically rewrites these fixtures. `result.json` deliberately says
PASS even in a failing case: T029 must preserve the observed exit and must never
upgrade execution observations to qualification.
