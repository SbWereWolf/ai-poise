## Принятые границы

Неполные feeds остаются partial; нет токенных оценок из текста. Информация после последнего tool-result не объявляется измеренной. Tokenizer fixture считает codepoints только для проверки протокола и арифметики; не изображает реальный tokenizer модели. Open cycles не экстраполируются. Baseline не сбрасывается rework. Интеграционная польза не дублируется автоматически. Ошибка measurement не управляет качеством результата продукта.
