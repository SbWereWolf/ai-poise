# Осмотр тестового контракта DDD-02

Обновлено: 2026-09-06T17:23:00+05:00. Осмотр выполняет тот же агент, не независимый reviewer.

17 доменных тестов написаны до реализации. RED — 17 NotImplementedError контрактной заготовки, не ошибка импорта и не доказательство дефекта работающего приложения. Проверяются два соседних маршрута с разными сроками, planned→documented, метод, структурный аргумент, наличие/содержимое verdict, дополнительная секция, объединение правил, уникальные пути, явные phases, отсутствие defaults, запрет записи не на своём этапе, локальная инвалидация.

Тест с усилением требования скорректирован: вместо заведомо противоречивых двух точных количеств используются совместимые минимумы. Доказательство сохранения обоих источников не требует неразрешимого сценария. Установление правдивости аргумента не тестируется механически: проверяются только структура и ссылки. Количество файлов не называется количеством тестов.

Следующий слой испытаний — реальный Task/UoW/SQLite и CLI verify: отсутствие секции останавливает до команды; заполнение+регистрация одним submission; post-gate; сохранение истории и повтор; отмена минует gates. Happy path использует точные методы учебного проекта.
