# Осмотр кода и исправлений DDD-05

Обновлено: **2026-09-06T22:06:40+05:00**. Осмотр тем же агентом, не независимый reviewer.

## Что осмотрено
Доменные владельцы Sprint/Task, пакетное применение, slots доступной задачи, atomic publication, область request identity, cancellation/waiver, изоляция worktrees, точное использование result commit, registry selection и обязательные конфиги. Нормальный путь проверяется настоящими SQLite, Git и subprocess, не только mocks.

## Найдено и исправлено
1. Общий creation validator первоначально потерял конкретный ID неизвестного метода. Прежний тест `test_unknown_method_rejected_at_creation` вернул отказ. CheckRegistry теперь выдаёт список missing IDs, проверка вновь зелёная.
2. Receipt запроса был глобальным для всей БД. Два разных спринта с одинаковым request_id ошибочно конфликтовали. Воспроизведено отдельным тестом до исправления; ключ стал `(sprint_id, request_id)`.
3. Force-close неполного draft проверял наличие опубликованных Task и откатывал корректную отмену. Воспроизведено; cancellation projection теперь не требует materialized membership у unpublished draft.
4. Ранее Task.sprint_id позволял свободную строковую метку без настоящего Sprint. Теперь membership создаётся через публикацию; прямая новая Task либо standalone с explicit null, либо выбирается из опубликованного Sprint. Старые artifact/demo fixtures адаптированы через реальный Sprint API, не ослаблением проверок.
5. Workspace preparation было продублировано в двух путях. Создание отдельной и Sprint-задачи использует один метод; domain всё равно не делает I/O.

## Поправки испытательного стенда
- Первая команда нового result-dependency fixture создавала pycache в контролируемом дереве. Добавлен явный `-B` в **тестовый invocation**, правило неизменности дерева не ослаблялось.
- Demo сравнивал исходник с строковым предположением о пробелах. Теперь сравнивает точное исходное содержимое до/после.
- Первая копия для повторного suite ошибочно исключила все каталоги с именем evidence, включая домен и тесты. Этот запуск остановился на импорте и не засчитан PASS. Копирование исправлено: исключается только корневой архив результатов; полные src/tests сохранены.

## Что не изображается реализованным
Нет автослияния разных predecessor commits; нет общего resolver межкодовых баз, runtime hooks/remote Gmail и полного recovery внешних эффектов. Нет подмены решений осмотра истинностью автоматически: reviewer decisions demo являются fixtures. Декларативное создание и валидация draft не превращают семантический план автоматически в правильный план продукта.

## Мутации
Проверены копии, намеренно допускающие VERIFIED как завершённого predecessor, убирающие Sprint scope receipt и допускающие цикл графа. Каждая обнаружена соответствующим поведенческим тестом. Протоколы в evidence/ddd-step05. Это направленные регрессии, не доказательство всех возможных дефектов.
