# Осмотр тестов DDD-07C

2026-09-07T01:42:01+05:00.

Тесты описывают реальные command subprocess, локальный MCP stdio peer и запуск сгенерированного launcher; не объявляют peer живой IDE. Hook JSON соответствует прочитанному публичному контракту Codex. Конфликтуют не Task-claims, а редактируемая конфигурация — допустимый обычный случай. Проверяются повтор, отсутствующие параметры, независимые сессии, отсутствие исходного prompt в БД, read-only не меняет lifecycle. MCP нужен handshake, tools/list и необязательный явно read-only smoke с проверкой projectPath; одно наличие имени инструмента не доказывает корректность rename.

Первый RED: отсутствуют новые modules/capabilities и modules/hook_transport. Это RED контракта API, не воспроизведение дефекта приложения. Прежние 456 продуктовых тестов будут сохранены и прогнаны отдельно. Установка не меняет feature/trust config Codex. Привязка текущей задачи без hook/сбор всей UI-телеметрии не обещаются.
