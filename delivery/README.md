# Состояние поставки AI poise

Однократная подготовка проекта завершена. Этот каталог не содержит определений
для повторного создания начальных задач и не является вторым хранилищем требований.

**Requirements DB** — единственный канонический реестр: 6 утверждённых требований
и 4 связи импортированы через публичный API. Полные тексты и статусы `future`
сохранены без переименования исторических идентификаторов. Точный повтор импорта
не изменяет ревизию. Статус `future` не означает, что каждое из этих требований
уже реализовано.

В полном переносимом архиве снимки находятся в
`projects/ai-poise/database/tasks.sqlite` и
`projects/ai-poise/database/requirements.sqlite`. Материалы `0106` содержат квитанцию
импорта, а материалы `0067` — повторную сверку текстов, статусов, связей и контрольных
сумм до удаления временных файлов. Исходные данные остаются в Git-истории и прежних
полных резервных копиях, но не используются как текущая конфигурация.

Восстановление выполняется в новое место. Живой Requirements-путь должен быть
явно выбран вне обслуживаемого Git checkout; архивный снимок нужно восстановить
туда, а не создавать вместо него пустой реестр. Подробности:
[импорт и восстановление требований](../docs/workflows/requirements-registry.md#однократный-импорт-утверждённой-поставки),
[настройка проекта](../docs/configuration/project-setup.md#локальный-проект-ai-poise),
[работа в WSL](../docs/configuration/wsl-local-delivery.md).

Новые Task и Sprint публикуются штатными владельцами после явной постановки.
Установка проекта сама по себе не создаёт начальный Sprint. Рабочие задачи,
опубликованные договорённости и их история читаются из Task DB; прежние задачи
не переписываются. Полная резервная копия включает Git, постоянные базы,
материалы задач и журнал, а не только коммиты.
