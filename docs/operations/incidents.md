## 0035 — проверка выполнилась не над подтверждённым task source

- Статус: исправлено task 0037.
- Evidence: `projects/ai-poise/task/0035/runs/192bad99-7384-4fd0-85f5-b56b4ba05f2b/response.json`.
- Наблюдение: в одном ответе implementation-проверки `CLOCK_GREEN` завершилась с exit 0 и
  `7 passed`, но `T0035_CLOCK_GREEN` и `T0035_ACCOUNTING` завершились с exit 1; полный
  accounting-набор сообщил `7 failed, 50 passed`.
- Причина: verification method не содержал обязательной provenance проверяемого исходника.
  Среда запуска могла разрешить импорт из другого checkout, поэтому зелёный результат узкой
  команды не был связан с task worktree. Реестр также не запрещал некоторые дублирующие или
  конфликтующие методы до выполнения.
- Воздействие: этап не был ошибочно подтверждён, потому что остальные guards отказали, но
  отдельный PASS и ранее допустимый RED нельзя было считать доказательством task change.
- Исправление: новые методы требуют `source_under_test`; runtime разрешает repository bindings
  внутри текущего worktree, фиксирует `provenance_digest` и `expectation_digest`, отклоняет
  коллизии/неразрешимые пути до subprocess, а `CheckRegistry` запрещает semantic duplicates и
  конфликтующие ожидания. RED дополнительно требует явный nonzero failure marker.
- Ограничение: исторический response остаётся неизменным доказательством события; он не
  переписывается и не переименовывается в успешный запуск после исправления.
