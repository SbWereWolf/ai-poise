# ERP-MIG-F3-07-C029-4

Обновлено: 2026-09-16.

Реализован авторский архитектурный gate AI-poise в существующем DevelopmentRouting.

Использованы прежние Python boundary/Task-owner ограничения и явная policy `config/testing/architecture-boundaries.json`. Единственная инфраструктурная проверка читает конкретные файлы копии AI-poise; чистый AST owner не исполняет subject code. Нет универсального multi-language dispatcher, второго runner, lifecycle или allowlist платформы.

Operational registration загружается из выбранной routing policy, не из проверяемой папки. Штатный `produce` подключён в поставленной routing-конфигурации, персональный project manifest не переписывался. Без registration — not_configured, не PASS. Runtime перед submit проверяет cumulative Git diff и неигнорируемые untracked files; удаления подтверждаются Git. Нарушение и inconclusive блокируют submission с file/line/rule/symbol и SHA-256 байтов. Исправление повторяется в той же Task/stage; claim, version, attempts, pending и history после отказа не меняются. Проверены отдельная рабочая папка и обычный checkout без worktree.

76 targeted/regression passed, 6 bounded smoke passed, ссылки/skill references и git diff --check без ошибок. Начальные failures и исправленная неодинаковая семантика glob/all-enumeration сохранены. Ошибка fixture с отсутствующим handler была отдельно исправлена; она не выдаётся за продуктовый RED. Полный suite и live IDE/host не запускались.

Контракт и ограничения: [проверка архитектуры перед авторской сдачей](../../workflows/architecture-boundaries.md#проверка-архитектуры-перед-авторской-сдачей). Проверка статическая, не полный data-flow и не filesystem transaction; неподдержанные поверхности явно unchecked, replay verified сохраняет прежний контракт. Independent review и пользовательская установка не заявлены.

Состав и зависимости: [актуальный F3](../f3-execution-plan.md). Task DB/lifecycle не изменены. Самопроверка не является независимым ревью.
