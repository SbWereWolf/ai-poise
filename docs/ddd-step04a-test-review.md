# Осмотр тестов DDD-04A до реализации

Обновлено: 2026-09-06T20:26:43+05:00. Осмотр выполняет автор, не независимый reviewer.

Проверяются байты реального config-файла, реальные SQLite receipts, CLI через subprocess и действующие доменные валидаторы. Forward references проверяются на финальном кандидате. Изменение порядка независимых записей не меняет результат. Нет испытания «совместить все невероятные ошибки».

Начальный RED подтверждает отсутствие `GoalTypeDefinition`/`goal_config_tools`. Все сведения о будущих тестах остаются ожиданиями. Реальные проверки будут отражены в итоговом протоколе.

Нужно дополнить: продолжение активной задачи после изменения pack; crash после замены файла до completion receipt; повторный запрос с прежней revision. Проверки самого шаблона не доказывают инженерную разумность созданного процесса.

Дополнения выполнены: snapshot активной/новой Task, failure до/после atomic replace, старый replay, смена target при pending, невозможный output budget и настоящий CLI demo. Содержательный RED сохранён отдельно от начального import RED.
