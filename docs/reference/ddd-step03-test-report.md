## TDD и осмотр

28 начальных тестов были записаны и закоммичены до библиотечной реализации. RED — отсутствие workflow API, не подмена теста предметного поведения отсутствующим interpreter. После реализации чистые тесты стали GREEN. Отдельная проверка осмотра воспроизвела реальный дефект continue на изменённом после доклада дереве (DID NOT RAISE); после исправления тест прошёл.

Проверены короткий и полный feedback на development/documentation. Сценарные решения: находка → первое предложение → rejected → второе предложение → accepted. Одна Task, разные сохранённые iterations; после reload счётчики не исчезают. SQLite-trigger доказывает реальный rollback связанных данных.

CLI-драйвер делает реальные commands/commits/push в локальные учебные bare remotes. Основная main приложения остаётся неизменной. Reviews, evidence-текст и пользовательские инструкции в драйвере заданы тестовыми данными; это не независимое review модели.
