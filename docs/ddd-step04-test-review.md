# Осмотр тестов DDD-04

2026-09-06T18:49:00+05:00. Осмотр тем же агентом, не независимый review.

Тесты до реализации фиксируют: точный explicit план, command/logical разделение, отрицательный subject не ошибка исполнителя, guard остаётся блокирующим, CONTINUE привязан к receipt/состоянию, перезапуск не повторяет команду, отдельное решение осмотра, цикл отклонение→новая iteration→принятие. Реальные CLI/domain/SQLite/Git/subprocess данные; monkeypatch используется для явного изменения входной среды, не для подмены I/O успехом. RED сборки: отсутствует новая библиотека; этот RED не выдаётся за наблюдение дефекта старого поведения. После появления API отдельно проверяем содержательный RED/GREEN.

Дополнительные проверки после реализации: rollback при сохранении доказательств; неизвестные ID/невалидный verdict; чистота библиотек; сохранность raw outputs после cleanup. Сохранён прежний набор регрессий. Новая schema обязательна, старые fixture будут явно обновлены, не обходятся runtime fallback.
