# Bounded task context

State the requested outcome, exact inputs, scope and output contract. Keep behavior rules distinct from references and examples. Load the current Task/stage and the smallest necessary context, not every historical artifact or every catalogue skill.

Discover paths/headings/matches before reading large sources. Batch independent bounded reads through existing owners and follow exact revision/line ranges when evidence requires more. A preview or truncated response is not complete source inspection. Preserve complete logs and durable summaries in existing artifact/content owners and link them rather than copying them into every prompt.

Use an available session-aware reader for revision-aware reuse; do not invent a cache receipt, claim an unchanged result without comparison or install a copied read registry to justify instruction changes. Compaction summaries carry provenance and unresolved obligations, not authority to advance a Task.

Examples must match the installed API and runtime. Optional capabilities are conditional; do not repeatedly request an unavailable tool or silently fall back to a different owner. Never claim quantified token/runtime savings without a measured baseline and comparable experiment. Check routing, links and examples after instruction changes.
