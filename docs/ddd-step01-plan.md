DoD: задача принимает пакет секций одним вызовом; повтор идентичного payload не размножает текущий слой; A→B→A сохраняет три результата; новое дерево при прежнем payload перепроверяется; verify не запускает следующий этап; accept/rework/cancel выполняет Task. Строки секций находятся в SQLite TEXT и защищены FK; state/слои/события пишутся атомарно. Старый store v1 отклоняется без миграции.

Проверки: доменные unit tests, SQLite round-trip/rollback/FK/конфликт версии, адресное чтение, архитектурные ограничения импортов и записи, существующий CLI development demo, один сквозной rework с сохранением обоих report.

Команды: `PYTHONPATH=src python -m pytest -q`; `PYTHONPATH=src python examples/demo.py --directory <new-empty-directory>`. Все fixtures — временные локальные репозитории; внешние сервисы не используются.
