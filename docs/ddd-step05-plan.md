# HARNESS-DDD-05 — Sprint API

Срез начат: 2026-09-06T21:41:41+05:00. Цель: пакетное планирование, публикация и прохождение малого спринта через существующие Task/runner.

## Владелец и маршрут
Sprint владеет draft, составом, зависимостями и пользовательскими решениями. Task владеет созданием, запуском и завершением своей работы. Общие SectionBook, Task creation validator и UoW переиспользуются. Работающий конфиг не редактируется вручную; запросы — JSON stdin в `work`.

Путь: один draft-пакет → feedback об отсутствующих полях → исправляющий пакет → атомарная публикация → bootstrap спринта со всем eligible set → выбор задачи по ID → обычный work/verify/accept → автоматическая новая сводка → successor получает проверенный результат predecessor → спринт завершён.

## Граница
Одна зарегистрированная codebase проекта, как в DDD-04B. Result dependency выбирает commit, содержащий все нужные результаты; расхождение веток блокирует запуск с предложением интеграции, не выполняет merge. Full suite не запускается. Статусы самостоятельных задач и новые правила Sprint не меняют формат их содержательных payloads. Полное перепланирование уже начатого Sprint, recovery Git и 13 готовых packs не входят в этот срез.

## TDD
Тесты SprintPlan/политики/графа, SQLite-публикации, batch API и полного Git пути создаются до реализации. RED в evidence/ddd-step05/red.txt — отсутствующий новый API, не воспроизведение дефекта существующего приложения. Далее осмотр тестов, реализация, GREEN, осмотр/регрессии, docs и два архива.
