## Область действия

Этот комплект конкретизирует последнюю декомпозицию runner/handler и актуальные упрощения артефактов. Он не заменяет собственные правила 13 типов целей, не возвращает смысловые artifact_declarations и не вводит новые административные действия агента.

Продукт остаётся модульным Python-приложением для Linux в ChatGPT и Codex WSL. Одна поставка, одна локальная SQLite, каталоги внутри configured state root Harness. Нет микросервисов, обязательного брокера, ORM-фреймворка или event sourcing.

Все таблицы, методы и структуры каталогов ниже — проектные контракты, а не уже реализованные API. SQL DDL, новые рабочие модули, runtime-конфиги и миграции не создавались. Поддержка старой БД автоматически не вводится.

`reference/` содержит неизменённые исходные материалы с собственными прежними timestamps; это основания сопоставления, не второй действующий комплект правил. `data/` — компактный каталог принятых здесь границ и соответствий; не runtime config.
