# HARNESS-DDD-07 — локальный путь адаптеров, результатов и handoff

Создано: 2026-09-06T23:40:23+05:00

Контракт: один пакет runtime адаптера вызывает существующий WorkTools. Идентичность сессии включает проект, источник, внешний ID и agent ID. События пользователя импортируются из явного Codex JSONL только по event_msg/user_message; нечитаемые/частичные события не выдумываются. Capability inventory передаётся явно и не изображается обнаруженным CLI.

Command result фиксируется в прежнем task run, один parser в primary/materialize modes создаёт компактное представление синхронно и все configured файлы асинхронно. Перед возвратом verify материализация доводится до ready либо отдельного Incident; командный вердикт не переписывается. Большие outputs читаются потоково.

Local handoff: Task owner освобождает работу только после сохранённого commit/checkpoint и receipt с process position; следующий actor возобновляет ту же итерацию в том же store/worktree. Опциональный payload позволяет сохранить незавершённый содержательный результат без verify. Никакой приёмки WIP. Неизвестные команды и начатый незавершённый merge не повторяются. Полный межмашинный импорт, Gmail и установка hooks IDE вне среза.

TDD: домен/выходы/дедупликация → реальные файлы/subprocess/SQLite → CLI/handoff → осмотр/регрессии → полная проверка и архивы. Старые форматы отклоняются; миграций нет.
