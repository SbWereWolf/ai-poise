## Цель, польза и выполненный путь

Цель — разделить средства проверки по ответственностям, чтобы каждую
необходимую возможность можно было использовать отдельно. Правила профилей,
их проверка и сериализация получили одного владельца; конфигурация выбирается
на одной границе и передаётся явно. CLI и MCP используют общий исполнитель.

Польза — меньше расхождений между точками входа, явный отказ при неверных
обязательных настройках и возможность проверять отдельные части независимо.
Выполненный путь: выделение владельцев, исправление проверки обязательных
параметров, независимая приёмка, разрешение конфликтов, повторные проверки
и штатная интеграция с сохранением чужой работы.
