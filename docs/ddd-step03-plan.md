# HARNESS-DDD-03: графовый runner и обратная связь

Создано: 2026-09-06T18:00:02.702135+05:00

Владелец маршрута/переходов — Task с чистой RouteDefinition; история замечаний и предложений исправления — общая доменная FeedbackBook. Прикладной StageRunner вызывает TaskCommands; Git/tests/storage остаются общими сервисами.

Результат: явный граф вместо index+1, produce/inspect/revise, read-only осмотр, проверяемое предложение исправления и отдельное решение повторного осмотра, сохранённые счётчики посещений/переходов, одна задача при возвратах. Один успешный verify не начинает следующий этап. Приём и продолжение различаются.

Приёмка: короткий путь и цикл reject→fix→inspect→accept на development и documentation через реальные Git worktrees и SQLite; чистая библиотека проверяет произвольные имена и порядок stage, invalid config, пределы, исторические результаты и отмену. Новые исходники до RED не пишутся.

Не включены в срез: observe/check PREPARE/CONTINUE, межзадачные product findings, Sprint, миграции, внешние IDE/cloud services. Явные ошибки сохраняют состояние, не имитируют автоматическое восстановление.
